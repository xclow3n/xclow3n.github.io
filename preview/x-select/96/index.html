Smuggling Shouldn't Exist Anymore, Right?

Connection reuse is a trust decision, and ten products make it on a connection where the previous request is not finished. Reuse is not the defect: turning it off takes the crossings to zero and leaves every one of them in place. Four mechanisms: pre-grant write, unproven-drain reuse, promise-credited framing, reset-with-debt. Wire traces, origin logs and a control for each. CVE-2026-56866.

Four ways a connection changes owners while it still owes the previous request’s bytes.

Breaking Pingora: HTTP Request Smuggling & Cache Poisoning in Cloudflare's Reverse Proxy

Between December 2025 and January 2026 I found three request-smuggling bugs in Cloudflare’s Pingora and one cache-poisoning bug: `CacheKey::default()` keys on the URI path alone, so evil.com and victim.com share a cache entry for the same path. All four work under Pingora’s default configuration.

Cloudflare’s own CDN stack sits behind upstream layers; direct Pingora deployments are exposed. Fixed in Pingora 0.8.0, $5,000 in bounties.

Three smuggling bugs and a cache key that ignores Host, all in Pingora’s default configuration.

HTML Sanitize Bypass Using MXSS

I went looking for sanitizer bypasses to harden a CTF challenge, and found one in sanitize-html. htmlparser2 parses everything inside `<style>` as raw text, so `<math><style><img/src=x onerror="alert(1)"` passes through; the browser then closes both tags per HTML5 and leaves a live `img` with the handler attached.

It needs `style` and `math` in `allowedTags`; the library already warns about `style`. At the time of testing, v2.13.1 still behaved this way.

Mutation XSS through sanitize-html, where htmlparser2 and the browser disagree on style and math.

Email Parser Discrepancy in Nodemailer

Nodemailer’s address parser splits at the first `@` outside a properly recognized quoted local-part, so `"test@0xhexr4.htb"@google.com` loses `google.com` as its domain. I found that first case while building a CTF challenge; Nodemailer called it a regular bug and fixed it in v6.9.16 without credit.

A second payload, `"xclow3n@gmail.com x"@internal.domain`, routed to gmail.com instead. I reported that one as a security advisory, GHSA-mm7p-fcc7-pg87, patched in v7.0.7.

Two address-parsing bugs that misroute mail. Patched in v6.9.16 and v7.0.7.

EncoDecept: HTB University CTF 2024

My intended solution to EncoDecept, HTB University CTF 2024. The challenge’s Nginx caches by file extension and Rails treats `.` as a path delimiter, so `/settings.ico` poisons the cache. With no charset declared, a JIS X 0208 1978 differential turns a markdown bio into XSS in Chrome.

Running as `contract_manager`, a Django ORM leak brute-forces the admin password, then a controller merging request params over its `Marshal` payload gives RCE.

Intended solution: web cache deception through a Rails path delimiter, then a Django ORM leak.
